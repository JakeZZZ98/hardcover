# Book Pattern textures (Poly Haven, CC0)

- Source: https://polyhaven.com/a/book_pattern, by Rob Tuytel.
- License: CC0 1.0 (public domain; free for any use, no attribution required).
- Downloaded 2026-09-14 at 1K, JPG: `nor_gl` (normal map, OpenGL convention), `rough` (roughness), `ao` (ambient occlusion).
- Derived, also CC0:
  - `book_pattern_detail_1k.jpg`: the weave's light and dark, taken from the colour map (`col1`) with the colour removed.
    The renderer multiplies it onto any cloth colour, so the weave survives a recolour.
  - `book_edge_band.jpg`: a strip cut from the `page` map, its ends blended so it tiles once along the fore-edge.
